Respostas rápidas

O que é o The Carousel Maker?

Um app de Mac para fundadores e criadores encontrarem carrosséis que já viralizam no TikTok, reunirem slides, textos e métricas no canvas e criarem carrosséis parecidos em lote com IA.

O app publica no TikTok ou no Instagram?

Não. O calendário organiza os arquivos e os horários planejados. Você revisa o conteúdo e faz a publicação manualmente em cada plataforma.

Como a IA entra no processo?

Você usa o Claude Code ou o Codex no terminal embutido para criar e ajustar os carrosséis com o contexto do projeto. É preciso ter a ferramenta instalada e conectada à sua conta.

A IA está incluída?

Não. Você usa sua própria conta compatível com Claude Code ou Codex, conforme as condições e os limites do provedor. O app não inclui créditos de IA.

O que eu preciso para usar?

Um Mac com chip Apple Silicon e macOS 26 ou posterior, internet para a pesquisa e a IA, e Claude Code ou Codex. Seus projetos e arquivos ficam no Mac.

Já posso comprar ou baixar?

O acesso público está em preparação. Entre na lista de espera para receber o aviso de lançamento. A inscrição é gratuita e não inicia uma assinatura.

O app garante que meus carrosséis vão viralizar?

Não. As referências ajudam a estudar formatos que já tiveram resultado, mas não garantem alcance, engajamento ou vendas para o seu conteúdo.
